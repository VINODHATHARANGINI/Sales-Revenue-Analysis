# Sales & Revenue Analysis Dashboard

## Project Overview
An interactive Power BI dashboard designed to analyze sales performance, revenue trends, profitability, regional sales, and top-selling products.

## Tools Used
- Microsoft Power BI Desktop
- Power Query
- DAX (Data Analysis Expressions)

## Key Performance Indicators (KPIs)
- Total Sales: 2.30M
- Total Orders: 5,009
- Total Profit: 286.40K
- Profit Margin: 12.47%

## Dashboard Features
- Sales analysis by region
- Category-wise sales distribution
- Yearly sales trend analysis
- Top 10 products by sales
- Interactive filters for order date, region, segment, and category

## Key Business Insights
- Technology has the largest share of sales in the displayed category analysis.
- The West region has the highest sales among the displayed regions.
- Sales increase considerably from 2015 to 2017 in the yearly trend.
- The product chart highlights the highest-selling products.

## Dataset
Source: [Sample Superstore Dataset](https://www.kaggle.com/datasets/vivek468/superstore-dataset-final)

Please check the dataset provider's license and attribution requirements.

## How to Use
1. Download the Power BI `.pbix` file from this repository.
2. Open it using Microsoft Power BI Desktop.
3. Use the interactive filters and charts to explore sales performance.
